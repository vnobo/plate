# ng-web

Standalone Angular 22 scaffold — a minimal, clean starting point for new frontend work.

## Tech Stack

- **Angular** 22.0.x
- **TypeScript** 6.0
- **RxJS** 7.8
- **Express** 5.1.0 (SSR server)

## Development

```bash
pnpm install
pnpm start              # dev server at http://localhost:4200
```

## Build

```bash
pnpm build              # production build
pnpm build:ssr          # SSR build
```

## Testing

```bash
pnpm test               # Vitest
```
